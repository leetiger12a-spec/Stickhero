# 레전드 히어로 (LEGEND HERO)

> 아들이 지은 이름. 저장소 이름·주소(Stickhero)는 그대로 둠

막대 영웅 서바이벌 게임 — 아빠와 아들이 함께 만드는 HTML5 게임.

- **현재 빌드: Build 194** (화면 오른쪽 아래에도 표시)
- 플레이: https://leetiger12a-spec.github.io/Stickhero/ (GitHub Pages를 켠 뒤)

## 그림 제작 규칙 (ChatGPT · 제미나이)
- 그림은 ChatGPT 또는 제미나이로 만듦. 반복되는 땅 무늬는 ChatGPT 우선 (제미나이는 오른쪽 아래 별 표시가 반복됨)
- 화질: **QHD(2560×1440) 이상** — **모든 프롬프트에 항상** `ultra high resolution, QHD (2560x1440) or higher, crisp clean lines` 포함, 가능하면 Gemini **Pro(Thinking) 모드**의 **2K/4K** 출력 사용
- 작은 그림은 **한 장 시트**(격자, 칸 사이 넓은 흰 여백)로 모아서 요청
- 흰 배경 · 글자 없음 · 게임 스프라이트 · 3/4 위에서 본 시점, 공통 문구도 프롬프트마다 전부 포함(복사·붙여넣기용)
- 받은 그림은 배경 제거·자르기·크기 조절만 (그림 내용은 수정하지 않음)

## 조작
- 📱 폰: 화면 아무 곳이나 끌면 가상 조이스틱으로 이동, 공격은 자동
- 💻 PC: WASD / 방향키 이동, P·Esc 일시정지, 레벨업 카드는 1·2·3 키

## Build 180 내용 — 부드러운 움직임·효과
- 🎞 **움직임이 부드럽게**:
  - 동작 그림(영웅 걷기·베기, 골렘 걷기)이 칸이 바뀌기 직전 다음 칸을 살짝 겹쳐 그려서 뚝뚝 끊기지 않아요. 걷기는 칸 번호 대신 걸음 진행에 맞춰 이어서 재생.
  - 왼쪽↔오른쪽 방향을 바꿀 때 휙 뒤집히지 않고, 0.1초 동안 몸을 돌리듯 바뀌어요 (영웅·동료·몬스터).
- ✨ **효과가 부드럽게**:
  - 그림자가 딱딱한 타원 대신 가장자리가 흐린 그림자로.
  - 몬스터가 맞으면 하얗게 번쩍했다가 바로 꺼지지 않고 서서히 사라져요.
  - 반짝이·불꽃 파편에 은은한 빛 번짐이 생기고, 끝에서 스르르 사라져요.
  - 파편이 느려지는 속도가 화면 빠르기(30·60·120 fps)와 상관없이 같아요.

- 쓰러진 적이 금화 🪙를 떨어뜨림 → 점선 동그라미 위에 서면 금화가 들어가 망루 건설/강화(Lv 5), 울타리 강화·수리
- 망루는 자동으로 화살 발사. 영웅이 쓰러지면 4초 뒤 마을에서 부활, 마을이 무너지면 게임오버
- 적이 맞으면 눈이 > < 로, 쓰러지면 빙글빙글 날아감. 밝은 풀밭 맵(바깥은 숲)

## Build 1 내용
- 사방에서 몰려오는 적 3종(빨강 졸개, 노랑 날쌘이, 보라 뚱보) + 60초마다 괴물 떼 몰이
- 처치 → 경험치 구슬 → 레벨업마다 카드 3장 중 1장 선택(일시정지)
- 무기 4종(회전 칼·권총·산탄총·부메랑, 각 최대 Lv 5) + 능력 5종(체력·속도·자석·힘·연사)
- 3분마다 거대 보스(대왕 슬라임 → 강철 거인 → 불꽃 대마왕): 돌진·탄막·부하 소환
- 체력·경험치·레벨·시간·처치 수 표시, 게임오버/재시작, 최고 기록 저장(localStorage)
- WebAudio 합성 효과음 (🔊 버튼으로 끄기)
