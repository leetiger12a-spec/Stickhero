# 레전드 히어로 (LEGEND HERO)

> 아들이 지은 이름. 저장소 이름·주소(Stickhero)는 그대로 둠

막대 영웅 서바이벌 게임 — 아빠와 아들이 함께 만드는 HTML5 게임.

- **현재 빌드: Build 25** (화면 오른쪽 아래에도 표시)
- 플레이: https://leetiger12a-spec.github.io/Stickhero/ (GitHub Pages를 켠 뒤)

## 조작
- 📱 폰: 화면 아무 곳이나 끌면 가상 조이스틱으로 이동, 공격은 자동
- 💻 PC: WASD / 방향키 이동, P·Esc 일시정지, 레벨업 카드는 1·2·3 키

## Build 25 내용 — 해금 · 엔딩

- ⚡번개 지팡이: 가까운 적부터 적→적으로 지그재그 번개(Lv 따라 튀는 수 증가)
- 🔨불꽃 망치: 쾅! 영웅 주위를 내려쳐 불꽃 고리 + 크게 밀쳐냄 + 화면 흔들림
- 🐶강아지 방패병: 체력 260·받는 피해 절반, 방패로 쾅 밀쳐내기, 가끔 멍멍 (그림은 Gemini 대기, 지금은 임시)
- 클리어 화면 '🎁 새로 열림!', 지도에 🎁 표시
- 10칸 완료 → '엔딩 보기' 3컷 이야기 (그림 end1~3 대기, 지금은 글만)

## Build 24 내용 — 모험 지도 10스테이지 · 별

## Build 23 내용 — SKYFANG 오마쥬 · 소리
- 🎵 배경 음악(SKYFANG 곡, 반복 구간 그대로): 시작 화면 title / 마을 a / 스테이지 숲 b·폐허 c·던전 d / 보스·대습격 boss — 상황 따라 자동 전환
- 🔊 SKYFANG 효과음 18개로 교체: 맞기·적 처치 펑·산탄·레벨업·경고·보스 등장·큰 폭발·돌진·쿵·울타리 부서짐·건설·폭탄 등 (못 불러오면 예전 합성음)
- 새 합성 효과음: 고양이 '야옹~'(동료 합류·가끔 공격 때), 통나무 쌓일수록 높아지는 '톡', 금화 연속 줍기 음 올라가기, 승리 환호, 폭탄 던지기·쉭
- ✈ SKYFANG 지원 폭격: 마을에 적이 몰리면 70~100초마다(대습격 땐 8초 뒤 반드시) SKYFANG 비행기가 날아와 적 무리 위에 폭탄을 줄줄이 떨굼
- 시작 화면 하늘에도 SKYFANG 비행기가 가끔 지나감
- 📳 진동(맞을 때·보스 착지·보스 처치·건설·방어 성공), 일시정지 메뉴에 🎵 음악 / 📳 진동 켜기·끄기, 시작 화면 🎵 버튼 (설정 기억)
- 음악·효과음 파일: `bgm/`, `sfx/` (출처: 같은 제작자의 SKYFANG 저장소)

## Build 12 내용 — 동료 고용
- 🏠 영웅 숙소(🪵12 🪙40): 망루 2개 또는 대장간을 지으면 열림. 지은 뒤 금화로 동료 고용(최대 4명, 🪙60·120·200·300)
- 동료는 검사 → 궁수 → 검사 → 궁수 순서. 영웅 주위 네 방향에서 따라다니며 싸우고, 스테이지에도 함께 감
- 검사: 가까운 적에게 달려가 칼로 베기 / 궁수: 멀리서 화살. 대장간 강화가 동료 공격력에도 적용
- 동료가 쓰러지면 12초 뒤 숙소에서 부활(스테이지에서 쓰러지면 마을로 돌아온 뒤)
- 검사 동료 그림: 주황 고양이(Gemini). 궁수·숙소 그림은 아직 코드 임시 그림
- 비싼 건설은 금화가 더 빨리 들어가게(최대 약 2초)
- 버그: 없는 그림 파일을 불러와 콘솔 오류가 나던 문제 수정(있는 그림만 불러오기)

- 스테이지 장식이 폰 화면 밖에 있어 안 보이던 문제 수정(길 가장자리 + 길 안쪽에 배치)

## Build 10 내용 — 자동 플레이 테스트로 찾은 문제 수정
- 버그: 출격 중에도 마을 난이도 시계가 흘러, 귀환하면 적이 갑자기 강해지던 문제 → '마을에서 보낸 시간' 기준으로 변경
- 버그: 스테이지 보스를 잡을수록 마을 보스 체력이 폭증하던 문제 → 마을·스테이지 보스 따로 셈
- 밸런스: 스테이지 보스 체력 1400 → 450(+스테이지마다 80%), 스테이지 적 무리 약간 축소
- 밸런스: 첫 마을 보스 체력 800(연습용), 보스의 울타리·마을 공격력 완화, 마을 체력 1000 → 1500
- 밸런스: 망루 강화는 금화만(통나무 불필요), 망루 화살 공격력·연사 상향, 적 증가 속도 완화, 대습격 30초·적 수 완화
- 성능: 그림 미리 축소 + 적 회전 제거 → 적 200마리 기준 약 28 → 47 FPS (헤드리스 측정)
- 테스트 도구: 치트 없이 키보드만으로 플레이하는 자동 봇(나무 베기·건설·출격·방어)

## Build 6 내용 — 첫 그림 적용

## Build 5 내용 — 대습격 방어 + 대장간
- 스테이지를 2번 깰 때마다 귀환 10초 뒤 ⚠ 대습격: 북소리·붉은 테두리, 3~4방향에서 35초간 군단 + 보스가 함께 쳐들어옴
- 막아내면 보상 🪙(60 + 30×회차) + 마을 체력 300 회복. 대습격 중에는 출격 불가
- ⚒ 대장간(🪵10 🪙20): 지은 뒤 금화로 무기 강화 Lv 1~10 (모든 공격력 +10%씩, 망루 화살 포함)
- 마을을 넓힘(울타리 반지름 135 → 165)

## Build 4 내용 — 출격!
- 첫 망루를 지으면 마을 남쪽에 ⚔ 출격 문이 열림 → 1초 서 있으면 스테이지로 출발
- 스테이지는 위로 뻗은 길: 숲 → 폐허 → 던전 순서로 반복, 갈수록 길고 강해짐. 적 무리는 영웅이 다가가면 깨어나 쫓아옴
- 길 끝 결투장에서 보스 등장 → 처치하면 금화 더미 + 🌀 포털 → 포털에 서면 마을로 귀환(스테이지 번호 +1)
- 스테이지에서 쓰러지면 '후퇴!' 하고 마을에서 부활. 출격 중에는 마을 시간이 멈춤
- 마을에 보스가 있을 때는 출격 불가

## Build 3 내용 — 3/4 시점 + 나무 베기
- 땅을 비스듬히 내려다보는 3/4 시점 (나무·울타리·건물·캐릭터는 세워서 그림)
- 숲 4곳: 나무 옆에 서면 자동 도끼질 → 통나무가 등에 차곡차곡 쌓임(기본 12개, 🎒 큰 등짐 카드로 +6). 벤 나무는 25초 뒤 다시 자람
- 건설 자리에 통나무 🪵 + 금화 🪙를 넣어 건설. 첫 망루 → 울타리 강화 → 망루 2·3·4 순서로 하나씩 열림
- 처음 하는 사람을 위한 안내 화살표·문구

## Build 2 내용 — 마을 지키기
- 가운데 마을(🏠 1000)과 나무 울타리(16조각). 빨간 막대 군단이 부대로 몰려와 울타리를 부수고 마을을 공격
- 쓰러진 적이 금화 🪙를 떨어뜨림 → 점선 동그라미 위에 서면 금화가 들어가 망루 건설/강화(Lv 5), 울타리 강화·수리
- 망루는 자동으로 화살 발사. 영웅이 쓰러지면 4초 뒤 마을에서 부활, 마을이 무너지면 게임오버
- 적이 맞으면 눈이 > < 로, 쓰러지면 빙글빙글 날아감. 밝은 풀밭 맵(바깥은 숲)
